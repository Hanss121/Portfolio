# Muhammad Jihan Portfolio

Portfolio website for Muhammad Jihan, featuring project case studies, responsive sections, and an interactive 3D project showcase.

## Tech Stack

- HTML
- CSS
- JavaScript
- Three.js
- Tailwind config

## Preview

Open `index.html` directly in a browser, or run a local static server:

```bash
python -m http.server 4173 --bind 127.0.0.1
```

Then visit:

```text
http://127.0.0.1:4173/index.html
```
